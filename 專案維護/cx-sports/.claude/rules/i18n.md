# i18n 多語系處理

> 多語系 key 的新增 / 對齊統一走腳本，**禁止 Claude 直接 Edit / Write i18n 檔案**。
> 理由：避免 token 浪費（一次 add 要動多個 locale 檔）+ 避免 `.properties` `\uXXXX` escape 編碼踩坑。

---

## 1. 涵蓋範圍

### 1.1 後端（cx-sport-app-service）

```
cx-sport-app-service/src/main/resources/i18n/
├── messages.properties        # default
├── messages_vi.properties
├── messages_en.properties
├── messages_ko.properties
├── messages_ja.properties
├── messages_th.properties
├── messages_zh-HK.properties
├── messages_ms.properties
├── messages_id.properties
└── messages_bn.properties
```

- key 慣例：`errorCode.NNNN`
- value 為 **`\uXXXX` Unicode escape**（Java `Properties` 規範）
- **後端目前無自動化 script**：請用 grep 確認現有 key，再用 Bash + python3 寫入（避免直接 Edit .properties）

### 1.2 前端（admin-frontend）

```
lion-frontend/admin-frontend/src/i18n/langs/
├── zh/global.js    # reference locale
├── en/global.js
├── vi/global.js
├── ko/global.js
└── ja/global.js
```

- Reference locale：**zh**（key 最完整）
- 其他 locale 對齊 zh 的 key 結構

## 2. 強制走 script

### 2.1 前端 global.js — `scripts/i18n-add-key.py`

```bash
# 在 after_key 後插入新 key（5 個 locale 一次寫入）
python3 scripts/i18n-add-key.py KEY AFTER_KEY ZH EN VI JA KO

# 例：在 gameTotalFee 後插入 rewardCommission
python3 scripts/i18n-add-key.py rewardCommission gameTotalFee \
    "打賞抽成" "Reward Commission" "Hoa hồng thưởng" "チップ抽成" "보상 수수료"

# 例：插入到最上方（after_key=TOP）
python3 scripts/i18n-add-key.py newKey TOP \
    "新欄位" "New Field" "..." "..." "..."
```

行為：
- key 已存在 → skip（不覆蓋）
- after_key 找不到 → fallback 到 TOP 並提示

### 2.2 後端 .properties — Bash + python3 寫入

後端沒有自動化 script，新增 key 用以下方式確保不踩 `\uXXXX` 編碼問題：

```bash
# 1. 確認 key 是否已存在
grep -n "errorCode.9999" cx-sport-app-service/src/main/resources/i18n/messages.properties

# 2. 用 python3 追加（保證 UTF-8 → \uXXXX 正確）
python3 - <<'EOF'
import os
key = "errorCode.9999"
values = {
    "messages.properties": "登录失败",
    "messages_en.properties": "Login failed",
    "messages_vi.properties": "Đăng nhập thất bại",
    "messages_zh-HK.properties": "登錄失敗",
    # 其他 locale...
}
base = "cx-sport-app-service/src/main/resources/i18n"
for fname, val in values.items():
    path = os.path.join(base, fname)
    with open(path, "a", encoding="utf-8") as f:
        # Java Properties 需要 ASCII-safe 格式，用 \uXXXX escape 中文
        escaped = val.encode("unicode_escape").decode("ascii")
        f.write(f"\n{key}={escaped}\n")
    print(f"[ok] {fname}")
EOF
```

## 3. Claude 操作規範（硬規則）

### ✅ 應該做

- 直接呼叫 `python3 scripts/i18n-add-key.py ...`
- 後端用 python3 安全追加
- 查 key 用 grep（不要 full read 整個 locale 檔）

### ❌ 禁止

- **禁止用 Edit / Write tool 直接改 i18n 檔案**（properties 或 global.js）
- **禁止用 sed / awk 批次取代 properties**（編碼會壞）
- **禁止用 Read 整讀 i18n 檔案**（單檔 500+ 行，token 浪費）— 要查 key 用 grep

### 子 Agent 規範傳遞

派子 Agent 處理涉及 i18n 的任務時，從 `agents.md §規範摘要對照` 的「i18n 異動」列抄規範進 briefing 即可，**不需重貼本段**。
