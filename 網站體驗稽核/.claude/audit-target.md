# 稽核目標與範圍設定

> **這是唯一需要你手動填的檔案。** 部署完 `.claude/` 後填一次，之後每次稽核 Agent 都讀這裡。
> **憑證不要寫在這裡** —— 只寫「環境變數名稱」，實際帳密用 `export` 設在 shell 或放 `.env`（並確保 `.env` 已 gitignore）。

---

| 項目 | 值 |
|---|---|

| 站點簡稱（產出資料夾用） | `<例：cxsport>` |
| 起始網址 | `<https://...>` |
| 站點類型 | `<電商 / 博彩 / SaaS / 內容 / 服務預約 / 金融 / 其他>` |

## 環境模式

**環境模式：`test`**

<!--
test        = 測試／預備環境，資料可拋棄。交易流程一律走到底（下單、下注、儲值、付款），並刻意試錯。
production  = 生產環境。停在最後一個可逆畫面，不實際送出。

## 授權網域

Agent 只會在這些 origin 上互動。跳出清單外的網域只會記錄「跳出去了」，不會繼續操作。

```
https://<主站網域>
https://<若有第三方測試金流閘道，列在這>
```

## 登入憑證（只寫環境變數名稱）

| 用途 | 帳號環境變數 | 密碼環境變數 | 備註 |
|---|---|---|---|
| 一般會員 | `UX_AUDIT_USER` | `UX_AUDIT_PASS` | `<等級／權限>` |
| `<VIP／管理端／其他角色>` | `<VAR>` | `<VAR>` | |

未設定環境變數時，Agent 只跑訪客範圍，並在報告註明「未提供憑證」。

**登入頁網址**：`<若不在主導航明顯位置，填這裡>`
**驗證碼／2FA**：`<無 / 有（Agent 會卡住，請提供可繞過的測試帳號）>`

## 關注目標

<!-- 這欄最影響報告品質。寫得越具體，Agent 越不會亂逛。 -->

- **希望使用者完成什麼**：`<例：完成註冊 → 儲值 → 完成一筆下注>`
- **最在意的流程**：`<例：註冊與儲值，客服回報這兩步流失最多>`
- **已知痛點**（可選）：`<例：手機版結帳按鈕有人反映按不到>`
